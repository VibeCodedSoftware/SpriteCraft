## File format compatibility

`.aseprite` files are read and written by code written for SpriteCraft from the format's published description. No Aseprite
code is included. Aseprite is a separate product and is not affiliated with SpriteCraft. PNG and GIF code is also written
for this app.

## Bundled art

`assets/templates/isometric-base-tileset.png` is the base isometric tileset behind File › New isometric tileset, supplied
by the SpriteCraft project.

## Palettes

Built-in palettes are generated by SpriteCraft's own code.
